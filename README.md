Repositório com os projetos, exercícios e práticas desenvolvidos durante a **Pós-Graduação em Engenharia e Arquitetura de Dados**.

O objetivo deste projeto é consolidar conhecimento técnico, aplicar boas práticas de engenharia de dados e documentar aprendizados ao longo da especialização.

# 🧠 Conteúdos Abordados

## 📐 Arquitetura de Dados

* Modelagem dimensional
* Modelagem relacional
* Data Warehousing
* Data Lakes
* Arquiteturas modernas (Batch & Streaming)
* Governança e boas práticas

## ⚙️ Engenharia de Dados

* Processos de ETL e ELT
* Manipulação de dados com Python
* SQL avançado
* Criação de pipelines
* Tratamento e validação de dados
* Containerização com Docker

## 🏗️ Projeto Aplicado

Projeto prático integrando:

* Extração de dados
* Integração dos dados
* Modelagem
* Persistência
* Análise em dashboard
